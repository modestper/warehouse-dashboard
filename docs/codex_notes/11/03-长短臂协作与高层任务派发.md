# 长短臂协作与高层任务派发

### 任务背景

用户进一步区分两个问题：系统是否让长短臂机器人协作，以及高层货物任务是否从派单时就排除 A1。本文核对当前 V5 轮式调度与接力源码，并运行已有能力边界测试。

### 关键结论

- **正常派单按完整任务能力筛选；现有协作主要是携货后的接力。** 两种机制同时存在。
- A1 不会被正常分配需要从第 2、3 层取货或向第 2、3 层放货的完整任务；第 3 层任务只能由 X3 操作高层部分。
- 高层出库货物一旦已经取下，A1 可以成为后续接力候选，继续送往地面出库口；但是否真正选中还取决于电量、空闲状态、路线与交接可行性。
- 高层入库货物接力后仍须放上高层，因此接收者必须具备该目标货位能力。第 3 层入库不能交给 A1 或 R2 继续完成。
- 目前没有常规的“长臂专门取放、短臂专门运输”主动拆单算法，也不会仅因短臂机器人臂长不足，就先给它高层任务再自动请求长臂协作。
- 针对正常准入、接力能力和恢复规划运行了 3 项已有测试，全部通过；这些测试使用旧 wide 布局夹具验证共享逻辑，不代表当前 medium 已发生真实 X3→A1 接力。

#### 正常派单和接力的区别

| 场景 | A1 能否承担 | 当前处理 |
|---|---|---|
| 从地面入库口取货并放到第 3 层 | 不能完整承担 | 初次派单排除 A1，由 X3 执行 |
| 从第 3 层取货并送往地面出库口 | 不能完整承担 | 初次派单排除 A1，由 X3 执行 |
| X3 已将第 3 层出库货物取下，需要交接后送出库 | 可以成为候选 | 剩余目标是地面出库口，A1 无需再次操作高层 |
| X3 携带货物，最终仍须放到第 3 层，需要交接 | 不能接手完成 | 接力候选必须具备第 3 层放置能力，当前为 X3 |

因此要区分“原任务关联高层”与“机器人后续是否还要操作高层”。接力时不会要求 A1 重新满足已经由 X3 完成的高层取货能力。

#### 接力怎样触发和执行

接力入口是 `backend/scheduling_v3/sim.py:request_assistance()`（第 715 行）。当前主要触发来源有：

- 携货机器人通过 `report_soc()` 收到低电量修正，电量不高于 `assistance_soc`（当前配置 25%），或剩余路径无法通过电量准入。
- live 扰动声明短时故障并要求交接，或携货机器人发生持续驱动故障。
- 显式的 `handoff` 扰动调用接力入口。

25% 判断位于 `report_soc()` 的反馈处理路径，不能理解为每个 tick 都对所有机器人进行“低于阈值就自动协作”的全局扫描。`medium19` 注册了 24% 低电修正扰动，但这不保证接力双方恰好是 X3 与 A1；`medium1728` 没有注册相同的示例扰动文件。

主进程会筛选无故障、空闲、空载且电量高于补能请求阈值的帮手机器人，再检查其剩余目标能力。系统不是按“必须换一种型号”选择帮手；同型号和跨型号接力都可能出现。

选定候选后，中央规划会合路线、交接停留、接收者后续配送路线以及交出者补能或故障停留计划，并检查交通预约和电量。交接完成时再通过 `transfer_custody()` 同时改变任务负责人和货物归属，产生 `cargo_handoff` 事件，不会在远距离直接变更持货者。

当前交接是二维状态与距离约束模型，使用约 1.1～1.6 m 的机器人中心距离范围和配置的交接服务时间；不模拟按型号机械臂总长计算的三维手递手逆运动学。

#### 关键代码位置

- `backend/scheduling_v5/sim.py:_select_assignment_unthrottled()`：普通派单按源、目标货位能力禁用不可执行配对。
- `backend/wide/sim.py:task_capability_requirements()`（第 172 行）：普通任务检查源与目标；`remaining=True` 时只检查后续目标。
- `backend/wide/sim.py:_assistance_helpers()`（第 241 行）：根据剩余目标筛选接力机器人。
- `backend/wide/sim.py:_coordinated_replan()`（第 223 行）：接力和恢复提交计划时保留能力约束。
- `backend/wide/sim.py:marker()`（第 249 行）：实际取货、交付和接收交接时再次验证能力。
- `backend/scheduling_v3/energy.py:validate_handoff()`、`transfer_custody()`：检查位置、空载、唯一持货者和任务归属，再转移货物责任。
