```bash

```

以上省略第二参数时目标库为 `neo4j`。如需自定义为 `warehouse-copy`，改用下面这一条（两条命令择一执行）：

```bash

```

第二参数只指定新容器内部的业务库名，源库仍为 `47687/neo4j`，容器名和端口沿用原规则。详见 [自定义目标库名说明](10-复制脚本支持自定义目标库名.md)。

脚本默认源为已确认的 47687/neo4j；发布该端口必须是唯一正在运行的容器。目标创建为 `warehouse-run-copy-<时间>-<进程号>`，数据卷另有独立名称，不共享源卷。目标限制为 3GB 内存、2 个 CPU 配额、最大 1GB heap、512MB page cache；不是与源库配置完全对齐的性能基准环境。

默认目标端口：

```text
HTTP: http://127.0.0.1:48474/browser/

```

脚本不会抢占已有端口；如果端口已被占用，Docker 会拒绝创建，不会停止已有容器。复制前及复制全程，源 run 应维持暂停/不再写入。
