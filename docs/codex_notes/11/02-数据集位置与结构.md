### 任务背景

确认当前仓库项目的数据集位置、目录组织、CSV 字段及与地图、运行配置的关系。

### 关键结论

- 仿真输入主要在 `data/examples/`，地图在 `data/layouts/`，运行参数在 `config/`；不是将全部信息放在一个 CSV 中。
- 当前轮式实时入口由 `config/live-wheeled-datasets.json` 注册，默认 `medium1728` 指向 `data/examples/wheeled-medium-peak/`。
- 默认输入为一小时 1728 个任务（864 入库、864 出库），初始库存 864 件；地图是 120×90 米、48 架、2304 货位。
- 数据包的必需文件是 `tasks.csv`、`initial_inventory.csv`、`manifest.json`；`validation.json` 为校验报告。
- 这些是合成仓库任务，不是吉林真实原始配送记录；CSV 不包含机器人轨迹、分配结果或电量行为。
- 七天 50112 任务样例使用旧地图，不能直接作为新 medium 地图的数据包替换使用。
- 本次按实际 CSV 读取统计数量，未修改输入数据、配置或运行结果。

#### tasks.csv：每行一个搬运任务

| 字段 | 含义 |
|---|---|
| `task_id` | 数据集内唯一任务 ID |
| `task_type` | `INBOUND` 入库或 `OUTBOUND` 出库 |
| `goods_id` | 货物唯一身份，用于关联初始库存与前后任务 |
| `release_time` | 任务释放时间 |
| `due_time` | 任务完成期限 |
| `source_id` | 起点，入库为逻辑 `INBOUND`，出库为货位 |
| `target_id` | 终点，入库为货位，出库为逻辑 `OUTBOUND` |

当前默认数据包中的真实样例：

```csv
task_id,task_type,goods_id,release_time,due_time,source_id,target_id
V3-T-0000350,OUTBOUND,INITIAL-00350,2026-10-27T00:03:02+08:00,2026-10-27T00:21:27+08:00,R05-L1-C6-F2,OUTBOUND
V3-T-0001541,INBOUND,V3-G-1541-0001,2026-10-27T00:03:02+08:00,2026-10-27T00:21:37+08:00,INBOUND,R14-L1-C5-F1
```

`R05-L1-C6-F2` 表示 R05 货架、第 1 层、第 6 个货位列、第 2 面。逻辑 `INBOUND/OUTBOUND` 由运行时选择实际收发工位。时间是包含时区的 ISO8601，任务期限必须晚于释放时间。

CSV 不预设 `robot_id`、实际完成时间、轨迹、SOC 或调度策略；这些由仿真生成。每条任务搬运一件货物。

#### initial_inventory.csv：初始库存

```csv
goods_id,location_id
INITIAL-00002,R20-L1-C2-F1
INITIAL-00003,R11-L1-C3-F1
```

说明仿真开始前每件货物存在哪个货位。默认 medium 高峰和 19 任务样例均有 864 件初始库存。

#### manifest.json 与 validation.json

- `manifest.json`：数据版本、地图版本与 SHA-256、开始时间、时长、随机种子、任务数量、生成来源以及 CSV 文件摘要。地图与数据包必须匹配。
- `validation.json`：格式、摘要、数量、库存依赖与参考库存范围的校验结果；`valid: true` 不能证明机器人实际运行一定按时完成。
- 当前 medium 高峰 manifest 声明合成来源；任务起点为 `2026-10-27T00:00:00+08:00`，时长 3600 秒。

#### 地图与参数如何配对

`config/live-wheeled-datasets.json` 将以下文件配为同一场景：

- 数据：`data/examples/wheeled-medium-peak/`
- 地图：`data/layouts/expansion-candidates/medium/layout.json`
- 运行参数：`config/wheeled-medium-100.json`

地图描述尺寸、货架、100 个 homes、100 个 docks、16 个 stations、通道、缓冲区与障碍物；运行参数描述 100 台机器人、速度 1.5m/s、取放时长、能量与换电参数等。`medium19` 还加载 `config/live-sample-disturbances.json`，用于运行扰动。

### 后续建议

- 快速调试选 `medium19`；当前默认高峰实验选 `medium1728`。
- 新数据按三份必需文件组织，并匹配 medium 地图；七日旧样例需先迁移与重新校验。
- 字段契约见 `docs/dataset-contract/contract/data-contract.json`；其中旧地图容量 1728 属于历史契约，当前 medium 容量以配对地图的 2304 为准。
