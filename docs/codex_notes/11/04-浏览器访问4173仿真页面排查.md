### 后续建议

如果浏览器位于个人电脑，在个人电脑终端运行（替换服务器IP）：

```bash
ssh -N -L 4173:127.0.0.1:4173 chioe@<服务器IP>
```

保持该SSH连接开启，再在同一电脑浏览器访问：

```text
http://127.0.0.1:4173/index.html
```

如果本机4173已占用，改用本地14173转发到服务器4173，并在浏览器访问本机14173：

```bash
ssh -N -L 14173:127.0.0.1:4173 chioe@<服务器IP>
```

VS Code Remote SSH也可在端口面板中转发4173，并使用其显示的本地地址。服务器上的s4173仍需保持运行。

若浏览器就在6000pro桌面本机，端口转发不需要；此时检查代理是否绕过localhost/127.0.0.1，并结合浏览器具体错误继续定位。本次没有替用户的个人电脑建立隧道。
