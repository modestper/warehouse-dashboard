# 全量任务集注册与统一启动

### 任务背景

用户希望把现有任务集都注册成可选的 `dataset-id`，统一选择输入。范围为 `data/examples/` 下已有的9套任务包；保留源CSV、原地图和实验配置，同时扩展现有无journal的Neo4j启动器，使注册后的别名可用于新启动。

### 关键结论

- 全部9套任务已注册到 `config/live-datasets.json`，离线列表均显示 `available=true`。
- 启动器支持 `--dataset-id medium19/medium1728/sample19/peak1728/day/peak-2h/hotspot-2h/continuous-2d/seven-patterns`，默认仍是 `medium1728`。
- 地图、位置表、移动模型、配置和扰动随注册项选择；旧36架输入保留legacy模型，medium输入保留48架wheeled模型，无需修改原CSV。
- 修复 `seven-patterns` 的失效目录，指向实际的 `data/examples/seven-patterns-20261028`；导入器支持其缺少可选 `source` 描述字段的manifest。
- 每个别名使用独立静态 `graph_dataset_id`，避免同版本、同日期的数据包混用任务和货物节点。保留medium1728原图谱标识，medium19改用独立标识，新启动的静态导入与运行态写入一致。
- 通过37项相关测试，覆盖真实输入校验、图谱节点隔离、启动参数、旧模型机器人拆分的一致性、地图/模型切换、控制与HTTP接口；七日50112任务另通过静态导入离线检查。
- 本次没有连接实际Neo4j写入、导入真实数据、启动完整Ray仿真或重启已有服务。`/home/chioe/.bashrc` 中 `s4173` 仍固定medium19；当前函数未新增第三个参数。
